# 微信小程序 · 吉他练习节拍器

用于木吉他和电吉他练习。当前实现第一阶段普通节拍器，采用“前台生成本地 WAV → 微信后台播放器”的播放方式，无需服务端生成音频。

- 40–240 BPM：加减、滑条或点击数字输入。
- 2/4、3/4、4/4，以四分音符计拍；可开关首拍重音。
- 电子、柔和两种提示音；手机音量键控制音量。
- 1、5、10 分钟练习，默认 10 分钟；支持暂停、继续、结束。
- 本地记住上次设置。播放或暂停期间修改参数，需要确认结束当前练习；下一次开始会重新生成并从头播放完整时长。
- 生成期间保持前台；完成后可以锁屏练习。圆点展示拍号，不是逐拍动画。

功能拆解、UI 布局和后续鼓伴奏范围见 [功能与UI规划.md](./功能与UI规划.md)；最初的验证方案见 [方案.md](./方案.md)。

## 运行

1. 微信开发者工具导入仓库根目录，小程序目录为 `miniprogram/`，使用项目配置中的 AppID 和有开发权限的微信账号。
2. 编译后，在模拟器检查设置、底部选择面板与错误提示；使用真机预览检查声音和后台播放。
3. 开始前选好 BPM、拍号、音色和时长，等待音频准备完成。切后台会中止尚未完成的生成，可回到前台重试。
4. 设置 → 查看诊断信息，可查看文件路径、生成记录、错误信息，或停止并清理文件。

播放中保留生成文件。结束后在前台清理；后台结束后回前台清理；异常退出的残留在下次启动清理。重新进入页面会保留本次运行中仍在播放或暂停的练习。

## 验证状态

用户已确认原验证版本可以息屏播放。当前产品版仍需在目标 iPhone 回归，不能将原版本结果直接视为新版通过；正式版后台播放还需审核。

微信开发者工具已编译通过，并在模拟器检查了首页布局、时长面板、生成播放、暂停继续和播放中修改参数的确认流程。

本地运行：

```sh
node --test tests/*.test.js
```

当前 14 项测试通过，覆盖 WAV 头、可变速度的拍点与重音、暂停继续、参数修改确认、本地设置、页面重进、生成中切后台、错误重试和文件清理。微信接口使用模拟对象，不代替真机测试。

真机回归建议：

1. 先用 1 分钟，分别试电子/柔和、2/4/3/4/4/4、首拍重音开关，确认实际声音与设置一致。
2. 测试 40、137、240 BPM；录制声音检查拍点，不以界面刷新时间判断精度。
3. 测试暂停/继续、取消与确认修改参数，确认恢复不重新开始，修改后重新开始按完整时长播放。
4. 用 5、10 分钟测试锁屏、切微信聊天与返回前台；检查声音连续性、生成耗时和结束后清理。
5. 单独测试来电、其他音频中断、生成期间切后台、重新进入页面和异常退出后重开。
