# 微信小程序 - 节拍器

用于吉他练习，目前是“前端生成本地 WAV → 微信后台播放器”的最小可行性验证。

需求、讨论结论与真机验证步骤见 [方案.md](./方案.md)。

## 运行

1. 微信开发者工具导入本仓库根目录，配置已使用 AppID `wx39b7134827b827f8`，小程序目录为 `miniprogram/`。
2. 编译后预览，用有项目权限的微信账号在 iPhone 扫码。
3. 选择 1 分钟生成音频，确认有声后锁屏；再用 10 分钟检查持续播放。
4. 如失败，记录界面中的 `onError` 信息、手机型号、iOS 和微信版本。

固定 120 BPM、4/4，前端合成提示音，不使用网络服务。支持本地路径和锁屏播放与否，以真机结果为准。正式版后台播放还需审核。

停止按钮会清理生成文件；异常退出的残留在下次打开时清理。锁屏期间保留正在播放的文件。

## 本地检查

安装 Node.js 后运行：

```sh
node --test tests/*.test.js
```

自动检查验证 WAV 格式、拍点间隔和页面生成/清理流程，不代表微信或 iPhone 播放已通过。
