# 内置鼓采样

来源：用户下载的 `[99Sounds] 99 Drum Samples.zip`，作者/来源站点为 99Sounds（99sounds.org）。原压缩包保留在项目父目录。

| 鼓组 | 底鼓 | 军鼓 | 闭合踩镲 |
| --- | --- | --- | --- |
| 声学鼓 | kick-acoustic01.wav | snare-acoustic01.wav | hihat-acoustic01.wav |
| 808 电子鼓 | kick-808.wav | snare-808.wav | hihat-808.wav |

这 6 个文件由原始单声道 44.1 kHz、24 位 PCM 转换为单声道 22.05 kHz、16 位 PCM，总计 125,232 字节；未打包其余采样。使用对称低通 FIR 后降采样，保留声音起点。

重建命令（仓库根目录）：

```sh
python3 scripts/prepare-drums.py
```

也可在命令后传入原压缩包路径。

原包 README.pdf 的 LICENSE 允许商业与非商业用途，但明确排除将素材用于另一个采样库或虚拟乐器。这里记录原始使用条件，不将其解释为无限制授权。当前为个人吉他练习中的预设伴奏实现，发布或扩大素材使用范围时需核对这些条件。

鼓伴奏按绝对采样位置安排击打并混音，保留跨分块和跨小节的采样尾部；为重叠声音预留固定余量，不通过连续切换短音频实现循环。
